Flash Desk Buddy

ESP32-S3 firmware + web app + Wi-Fi setup, all from this page. No PlatformIO, no CLI, no second Wi-Fi network to join.

Step 1 — Flash the firmware
  1. Plug the board in over USB-C.
  2. Click install below, pick the serial port when Chrome asks.
  3. If it doesn't show up: hold BOOT, tap RESET, release BOOT — then retry.
  4. Takes about a minute. Firmware and the PWA both flash in this one pass.

Works in Chrome / Edge on desktop (Web Serial API). Not Firefox, not Safari, not mobile.

Step 2 — Send Wi-Fi + keys over the same USB cable

Fill the form below first, then press the board's RESET button, then click Connect within a few seconds and Send. A fresh device listens on USB for about 20 seconds after boot before it falls back to its own deskbuddy-setup Wi-Fi hotspot — this is the alternative to joining that hotspot by hand.
